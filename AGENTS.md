
## Package & Environment Rules
- Always use `pnpm` for installs and scripts (`pnpm install`, `pnpm dev`, `pnpm run build`). Never use `npm`.
- This project uses React 18; install `@react-three/fiber@^8` and `@react-three/drei@^9` alongside `three` and `@types/three`.
